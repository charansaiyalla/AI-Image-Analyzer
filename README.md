# AI Image Analyzer

This project demonstrates an AI-based image understanding system built using deep learning.

## Features

- Image upload interface using Gradio
- Edge detection using OpenCV
- CNN feature extraction
- Feature map visualization
- Image caption generation using BLIP Transformer

## Technologies Used

- Python
- PyTorch
- OpenCV
- HuggingFace Transformers
- Gradio
- Google Colab

## Workflow

1. Upload an image
2. Detect edges using OpenCV
3. Extract CNN features
4. Visualize feature maps
5. Generate image caption using BLIP transformer
